<embed>

La etiqueta <embed> sirve para incrustar un archivo externo dentro de la página, como una imagen SVG o un PDF. Es una etiqueta de autocierre, así que no lleva etiqueta de cierre.

<meta>

La etiqueta <meta> sirve para añadir información sobre la página que no se muestra directamente en ella. Se coloca dentro del <head>. En esta página hay tres: charset indica la codificación de los caracteres (UTF-8, para que se vean bien las tildes y la ñ), viewport adapta la página a diferentes tamaños de pantalla, como los móviles, y description contiene una descripción de la página que usan los buscadores como Google.

<source>

La etiqueta <source> se usa dentro de <video> o <audio> para indicar el archivo multimedia que se va a reproducir y su formato. El atributo controls muestra los botones de reproducir, pausar y volumen.

<param>

La etiqueta <param> se usa dentro de <object> para pasar parámetros a un contenido incrustado. Se creó para configurar plugins como Flash o los applets de Java. Hoy está obsoleta: los navegadores ya no admiten esos plugins, así que ignoran <param> y no tiene ningún efecto visible. <link>

La etiqueta <link> sirve para enlazar recursos externos con el documento HTML. En este caso se utiliza para enlazar el archivo styles.css y aplicar estilos a la página.

<hr>

La etiqueta <hr> sirve para separar diferentes partes de una página mediante una línea horizontal.

Este texto aparece después de la línea horizontal.

<img>

La etiqueta <img> sirve para mostrar una imagen en una página web. El atributo alt proporciona un texto alternativo para describir la imagen.

<input>

La etiqueta <input> sirve para crear campos donde el usuario puede introducir información.
