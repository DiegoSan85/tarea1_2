<link>

La etiqueta <link> sirve para enlazar recursos externos con el documento HTML. En este caso se utiliza para enlazar el archivo styles.css y aplicar estilos a la página.

Etiquetas de autocierre by Diego

<br>

La etiqueta <br> sirve para hacer un salto de línea dentro de un texto.
Esta frase aparece en una línea diferente gracias a <br>.

<hr>

La etiqueta <hr> sirve para separar diferentes partes de una página mediante una línea horizontal.

Este texto aparece después de la línea horizontal.

<img>

La etiqueta <img> sirve para mostrar una imagen en una página web. El atributo alt proporciona un texto alternativo para describir la imagen.

<input>

La etiqueta <input> sirve para crear campos donde el usuario puede introducir información.
